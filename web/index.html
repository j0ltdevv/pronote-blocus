Étape 1 sur 2

Connecte ton compte PRONOTE

Lecture seule. Aucun mot de passe demandé en mode QR.

Comment récupérer le QR code
  1. Dans PRONOTE (Espace Élève), ouvre le bandeau du haut → QR code (passe en “version ordinateur” sur téléphone).
  2. Choisis un code à 4 chiffres → Générer.
  3. Fais une capture d'écran du QR et reviens ici.

Procédure officielle : doc Index Éducation.

Confidentialité
  • Lecture seule : rien n'est coché ni marqué comme lu dans PRONOTE.
  • Ton jeton est chiffré, ton code à 4 chiffres est oublié après usage.
  • Déconnexion = suppression du compte côté serveur.

Aucune donnée n'est partagée ou revendue. Capture lue uniquement sur ce serveur.

Sur téléphone : fais la capture d'écran du QR, reviens ici, puis touche « Choisir une capture » et prends la photo dans tes captures d'écran.

Pas d'ordinateur sous la main ? Se connecter avec ses identifiants

PRONOTE n'affiche le QR que sur la version ordinateur. Sans ordinateur, tu peux te connecter directement avec l'identifiant et le mot de passe que ton établissement t'a donnés.

Ton mot de passe est chiffré en base : PRONOTE en a besoin pour renouveler la session, donc il est conservé — jamais en clair, jamais dans un journal. La déconnexion supprime le compte et ce mot de passe.
